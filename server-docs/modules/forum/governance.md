## 权力结构与白名单

论坛采用「管理员白名单」制度。

### 管理员角色

- 管理员角色由配置白名单管理；同步时机与失效策略以实现为准。

### 角色分层

| 角色 | 职责 |
|------|------|
| SuperAdmin | 最高权限，可修改全局配置 |
| Admin | 访问审核队列、执行禁言、处理申诉 |
| User | 常规发帖与互动 |

## 自动化处置

为减少人工干预，论坛实现了基于反馈的自动化治理：

- 基于反馈的自动降级 / 审核 / 隐藏与联合处置；阈值与触发条件为实现细节（口径与 [内容安全](./moderation.md) 一致，公开文档不固定数值）。

## 开发说明

- **事务性**：所有角色变更必须在数据库事务内完成。
- **数据一致性**：角色变更后需失效对应的认证缓存。
