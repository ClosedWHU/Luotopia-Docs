## 评分聚合策略

评价状态变为「已核准」等时，系统对相关课程做**聚合重算**（全量或等价一致策略），保证列表展示的均分/样本与合规评价一致。

| 点 | 说明 |
|----|------|
| 为何不全靠增量 | 撤销、隐藏、再核准时全量更不易漂移 |
| 计入条件 | 仅合规/已核准样本；待审与违规不计入 |
| 性能 | 按课程维度触发；高频写入可防抖（以实现为准） |

具体 SQL 与字段以实现为准，公开文档不固定查询文本。

## 常见问题

**Q: 聚合重算的数据库压力如何控制？**  
A: 按 `course_id` 限定范围；可配合异步/防抖。

**Q: 为何某评价不进统计？**  
A: 未通过审核或已标记违规。
