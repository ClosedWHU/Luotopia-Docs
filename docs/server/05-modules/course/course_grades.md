# 课程给分与统计

## 模块概述
本模块负责处理匿名课程给分提交及绩点分布统计，是 Luotopia 核心教学辅助能力之一。其设计目标是为用户提供真实、匿名的给分参考，同时通过服务端聚合保护用户隐私。

## 核心功能
### 1. 匿名给分提交
用户可以针对特定课程提交自己的给分情况。为确保数据真实性，建议客户端在提交前通过 `whu_auth` 获取教务系统成绩截图或数据进行前端核验，但在服务端仅保存匿名化的统计维度。

### 2. 绩点分布统计
服务端会自动将提交的原始分数（或区间）映射到五个标准绩点区间：
- **Fail**: < 60
- **Pass**: 60 - 70
- **Good**: 70 - 80
- **Excellent**: 80 - 90
- **Top**: 90 - 100

### 3. 数据聚合逻辑
- **AvgScore**: 该课程所有提交样本的加权平均分。
- **SampleCount**: 参与统计的样本总数。只有当样本数达到一定阈值时，客户端才会展示统计图表，以防误导。

## 接口说明
- `POST /api/v1/course/grades/submit`: 提交给分信息。
- `GET /api/v1/course/grades/stats/{course_uid}`: 获取特定课程的聚合统计数据。

## 数据库模型
- `GradeSubmission`: 记录单次提交（匿名关联）。
- `GradeStats`: 缓存后的聚合统计表。
