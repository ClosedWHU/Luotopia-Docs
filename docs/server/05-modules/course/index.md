# 课程服务概览

课程服务是 Luotopia 的核心业务之一，旨在通过数据聚合为学生提供透明、真实的教学信息参考。

## 包含的功能专题

1.  **[课程评价系统](./review.md)**: 
    学生对课程质量的感性描述与量化评分。
2.  **[课程给分统计](./course_grades.md)**: 
    匿名的真实给分提交与绩点分布趋势分析。
3.  **[教务数据同步](../timetable.md)**: 
    从校内系统抓取最新的课程列表与排课信息。

## 数据流向
1. 用户提交评价/给分数据。
2. 数据进入审核流（AI 自动审核或人工抽检）。
3. 审核通过后，数据进入聚合计算引擎，更新课程的平均分与热度。
