# 消息通知

`internal/notification` 是系统级的信息分发中心，负责向用户推送系统公告、业务提醒及即时消息通知。

## 1. 通知类型
- **系统通知**: 由管理员发布的全局公告。
- **业务通知**: 如帖子被点赞、举报处理结果、课表同步成功等。
- **即时消息**: 转发自 `chat` 模块的私聊提醒。

## 2. 交付渠道
- **应用内通知 (In-App)**: 用户登录后在通知中心查收。
- **移动推送 (Push)**: 集成 Firebase Cloud Messaging (FCM) 或 Apple APNs。
- **邮件通知 (Email)**: 针对验证码及核心安全事件。

## 3. 设计逻辑
系统采用“发布-订阅”或“事务内写入”模式：
- 关键业务操作触发通知生成。
- 通知记录持久化到 `notification_records` 表。
- 异步 Worker 负责将通知推送至第三方渠道。
