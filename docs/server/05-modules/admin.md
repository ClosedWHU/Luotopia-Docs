# 管理后台 (Admin)

管理后台模块负责处理系统管理员发起的敏感操作，通过独立的安全验证与权限校验。

## 1. 核心功能
### 1.1 用户管控
- **权限授予**: 分配管理员权限、审核员权限。
- **状态冻结**: 封禁违规用户，限制其在论坛、课程评价等模块的活动。
- **邀请额度管理**: 调整特定用户的邀请码生成配额。

### 1.2 内容审核 (Moderation Center)
- **全局队列**: 查看所有被举报或 AI 标记为待审的帖子、评价、资料。
- **批量处理**: 支持一键忽略或批量删除违规内容。
- **操作审计**: 记录每一项管理员操作，确保治理透明。

### 1.3 系统配置
- **动态配置**: 在不重启服务器的情况下更新系统参数（如注册开关、全局公告）。
- **缓存管理**: 手动清除 Redis 缓存或触发数据重建。

## 2. 安全策略
- **独立的 Admin 路径**: `/api/v1/admin/*` 受到更严格的 JWT 声明 (Claim) 校验。
- **两步验证 (2FA)**: 对于高风险操作（如删除数据库记录），系统可配置强制二次验证。

## 3. 实现细节 (`internal/admin`)
- **Repository**: 使用 `internal/platform/database` 适配器直接操作跨模块数据。
- **Handler**: 封装了标准的操作响应格式，并自动记录 `AdminActionLog`。
