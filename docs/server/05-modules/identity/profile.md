# 账户与资料管理 (Account & Profile)

本模块负责用户的生命周期管理，包括注册、登录、资料更新及开发者设置。

## 1. 用户注册与登录
- 支持传统用户名/密码注册。
- 支持基于 OIDC 的第三方 SSO 登录。
- 提供匿名登录功能（受限访问）。

## 2. 资料管理 (Profile)
用户可以管理以下信息：
- 个人基本资料（头像、昵称、简介）。
- 账户安全设置（密码修改、多因素认证绑定）。
- 租户归属及权限视图。

## 3. 开发者中心 (Developer Center)
- 生成及管理 API Keys。
- 设置 API 访问速率限制及配额监控。
