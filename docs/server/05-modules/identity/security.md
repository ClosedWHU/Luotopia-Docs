# 安全与防御策略 (Security & Defense)

Identity 模块集成了多重安全机制，确保用户数据和系统的安全性。

## 1. 认证安全
- **JWT 签署**: 使用 RS256 或 HS256 对令牌进行签署，确保不可篡改性。
- **速率限制**: 针对登录尝试实施 IP 级别的速率限制，防御暴力破解。

## 2. 交互安全
- **Turnstile 集成**: 在注册及敏感操作时强制进行人机校验。
- **签名校验**: 移动端 API 请求支持基于密钥的 Hmac 签名验证。

## 3. 敏感数据处理
- **密码加密**: 使用 Bcrypt 进行高强度单向哈希存储。
- **脱敏处理**: API 返回的用户信息经过严格脱敏。
