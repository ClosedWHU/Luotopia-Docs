# 评价系统 (Reviews)

评价系统是课程模块的互动核心，允许学生对课程质量进行量化评分和文字反馈。

## 1. 评价流程
### 1.1 提交 (`CreateReview`)
- **多维度评分**: 支持综合、给分、工作量、收获感等多个维度。
- **匿名保护**: 用户可选择完全匿名或使用昵称。
- **查重逻辑**: 系统会检查同一用户对同一课程+教师组合的重复评价。

### 1.2 审核流 (`ApproveReview`)
- 所有新提交的评价默认为 `Pending` 状态。
- 管理员通过 `/api/v1/admin/reviews/pending` 队列进行批量处理。
- 只有 `Approved` 的评价才会参与课程平均分的计算。

## 2. 统计计算
### 2.1 课程得分
- 课程的综合得分通过 `AVG(rating)` 实时计算，或通过触发器更新至 `courses` 表。
- 只有评价数超过一定阈值的课程才会显示百分比排名。

## 3. 关联关系
- 评价与课程 (`course_id`) 和教师 (`teacher_id`) 强关联。
- 支持通过 `ReviewUID` 快速定位具体的评价详情。

## 4. 开发说明
- **数据隐私**: 虽然是匿名评价，但后端必须保留 `author_id` 用于防作弊及合规追踪。
- **敏感词过滤**: 提交评价时会自动调用 `internal/services/core/sensitive.go` 进行内容脱敏。
