# 贡献指南

欢迎加入 Luotopia 社区！无论你是修复 Bug、改进文档还是开发新功能，你的贡献都至关重要。

## 1. 行为准则

我们致力于营造一个包容、友好的社区环境。请尊重每一位贡献者，保持技术讨论的专业性。

## 2. 文档贡献流程

如果你发现文档中有错误、过时的信息或可以优化的表达，请遵循以下流程：

### 2.1 准备工作
- 确保你已安装 Node.js 18+ 环境。
- 克隆仓库并安装依赖：`npm install`。

### 2.2 编写规范
- 所有的文档变更必须符合 [文档编写风格指南](./style_guide.md)。
- **严禁直接翻译**: 如果是翻译英文文档，请结合中文语境进行本地化调整，确保逻辑流畅。
- **验证链接**: 提交前请运行 `npm run build` 以确保没有死链。

### 2.3 提交 PR
- 提交信息应清晰描述变更内容，例如：`docs: 修正身份验证流程中的 OIDC 状态描述`。
- 对于涉及重大逻辑变更的文档，建议附带相关的源码分析或截图。

## 3. 代码贡献规范

### 3.1 目录约束
- **服务端**: 所有的业务逻辑应位于 `server/internal/` 的对应模块中。
- **客户端**: 遵循 ViewModel + Riverpod 的状态管理范式。

### 3.2 测试要求
- 所有的功能开发必须包含对应的单元测试或集成测试。
- 在提交 PR 前，请确保所有测试在本地通过。

## 4. 沟通渠道

- **GitHub Issues**: 用于 Bug 报告、功能建议及技术讨论。
- **Discord/Telegram**: 实时交流频道（请在 README 中查找最新地址）。
