## 车辆 / 开锁 / 还车 / 车辆控制能力类别

车辆状态查询（HTTP 轮询）、扫码开锁、骑行中控制、还车结算、救援与头盔盒等指令类接口存在；头盔盒指令码与完整参数表存档于私有仓 `whu-ebike-re`。端到端流程见[车辆控制流程](../flows/unlock-return.md)。

- **扫码与车辆详情**：按车牌/扫码值取车辆详情（计价、电量、头盔盒、包车卡、跨区配置替换、需交押金标记、车辆报失状态）；地图 marker 点查详情；车牌解析为车辆 ID；用车可用性校验（校内车限制）；扫码前免押判断与附近车辆两个 key 仅定义未调用；
- **摆车任务**：判定该车是否需挪动、提交摆车前后照片；
- **锁与头盔盒**：盒详情查询、**指令下发端点**（已见「查询头盔在位」与「开锁」两类指令；指令码与来源枚举存档于私有仓）；
- **订单生命周期**：创建订单（扫码开锁）、进行中订单 10s 轮询、还车前判定快照（服务端下发强制还车/拍照申诉/AI 提示等开关驱动前端文案）、结束行程（多种可选组合：强制还车、跳过停车识别+申诉照片、区外还车付费）、拍照还车提交、订单错误信息 key 仅定义未调用；
- **骑行中控制**：临时锁车（硬编码超时常量）、重新开锁、区外临时通电救援（倒计时+画线）、临时关闭头盔检测（30 天两次限制）；
- **还车辅助**：停车区外还车原因上报、问题行程原因反馈、优惠停车点绑定；
- **预约**：提交/查询/取消三方法共用一路径；
- **评价**：行程评价（星级+标签；测试兜底 orderId 残留，见[其他发现](../findings.md)）；
- **订单查询**：行程列表（游标分页）、行程/订单详情；
- **门禁**：违停停用校验（阻断开锁）；
- **图片上传**：通用上传与问题反馈上传两个 multipart 端点——**不带任何 mg-* 签名头**（弱点，见[未签名的上传通道](../signing.md#未签名的上传通道)）。
