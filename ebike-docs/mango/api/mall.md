## 商城 / 赠品能力类别

存在以下能力类别的接口（完整清单存档于私有仓 `whu-ebike-re`）：

- **商品**：商品列表（押金页/骑行卡页的「赠品横幅」与商品橱窗）、商品详情；
- **商城订单**：创建/列表/详情/支付/取消/退款/确认收货——除列表外，明细操作调用点均在缺失的 shopping 分包（见[未定位调用点](./uncalled.md)）；
- **赠品**：赠品资格/领取状态查询（前端带轮询重试）、领取赠品（按收货地址生成商城订单后跳订单详情）。
