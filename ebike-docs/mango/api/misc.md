## 设置 / 消息 / 客服 / 埋点能力类别

存在以下能力类别的接口（完整清单存档于私有仓 `whu-ebike-re`）：

- **说明与配置**：首页「区域说明」弹窗图例（按城市差异化）、开锁页「使用说明」条目、行程评价标签（正/负两组）；
- **广告位**：首页视频号/直播广告位配置（配合微信 channels API 决定按钮文案）、广告位商品收藏与我的收藏列表；
- **企业微信客服**：按运营区取客服账号 ID（仅客服类型为 qywx 的区域启用，首页 1s 轮询直到取到）、会话结束使用计数（插件机制见[其他发现](../findings.md#插件企业微信)）；
- **前端异常回捞**：失败请求回捞端点——目前唯一调用点是实名认证失败，会把姓名+身份证号一并上报（弱点，见[隐私与合规观察](../findings.md#隐私与合规观察)）；该端点在错误处理里被显式豁免 toast；
- **自建埋点**：批量上报端点（事件入队，满 10 条或页面隐藏/卸载时分批 flush，fire-and-forget）。
