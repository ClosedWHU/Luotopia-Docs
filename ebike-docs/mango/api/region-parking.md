## 5.3 运营区域 / 停车点 / 导航

| 接口路径 | 方法 | 关键参数 | 用途 | 调用处 |
|---|---|---|---|---|
| `/miniMango/v1/operation/region/intersect` | GET | query: `center:[lat,lng]`(loginPre) 或 `[lng,lat]`(index/business)，`openid`，`isScanIntoMiniMango`(=`scene===1011`)，`scene` | **拉取运营区全量配置** → 写入 `globalData`：`regionId`、`city`、`findLostAward`、`operationPattern`(0禁停/1收调度费/2停车优惠)、`parkingPattern`、`dispatchCost`、`outRegionDispatchCost`、`enableDispatchCost`、`parkingDiscount{rate,content}`、`stockSearchRadius`、`enableDepositRefund`、`enableMangoBalance`、`rechargeDiscount.rechargeAmount[]`、`enableRegionDeposit`、`homePageAnnouncement{title,content,link}`、`enableWxPay`、`freeOrderTimeLimited{freeTrip,freeRideCard}`、`kfType`(=`qywx` 时启用企业微信客服)、`isFreeDeposit`。三处调用一致：形参是 `getRegionData(lat, lng)`，内部写 `center: [t, e]` 即 **`[lng, lat]`**，与 `checkOperationCity` 的 `location: [lng, lat]` 顺序相同 | `pages/loginPre/loginPre.js:150`；`pages/index/index.js:1882`；`packages/business/pages/recommendedParkingLot/recommendedParkingLot.js:87` |

| `/miniMango/v1/operation/parkingLot/near` | GET | query: `parkingPattern`(0 或 `globalData.parkingPattern` 或默认 2)，`center:[lng,lat]`(地图中心)，`zoom:16`，`regionIds:[...]`，`stockSearchRadius` | **附近停车区/禁停区/车辆点位**：`{oldParkingLots[], parkingLots[], noParkingAreas[], stocks[]}`；`stocks[].discountRate` 决定图标（`stock_d0..d9.png`），`stocks[].isFree` 或「区外车+区内+免时长」用 `stock_d0.png` | `pages/index/index.js:1764`；`packages/business/pages/recommendedParkingLot/recommendedParkingLot.js:118` |
