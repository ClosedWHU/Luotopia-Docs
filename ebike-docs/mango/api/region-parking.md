## 运营区域 / 停车点 / 导航能力类别

本组接口存在以下能力类别（参数表与区域 ID 白名单存档于私有仓 `whu-ebike-re`，白名单概述见[硬编码业务 ID / 常量](../findings.md#硬编码业务-id--常量)）：

- **运营区配置**：按定位拉取运营区全量配置（运营区 ID、城市、报失悬赏、调度费模型、停车模式、押金/退款/充值开关、首页公告、客服类型、免押形态等），写入全局状态；三处调用点的经纬度参数顺序存在实现不一致的隐患（见[其他发现](../findings.md)）；
- **城市判定**：判定所在城市/运营区，区域 ID 白名单驱动差异化行为（首单免费开关、导航栏标题、张家界停运弹窗、武汉/东西湖标记）并决定押金形态；**请求失败时前端置越界标记，此后所有车辆控制请求被前端短路**；
- **停车区与车辆点位**：附近停车区/禁停区/车辆点位（折扣率决定图标）、目的地周边推荐停车点、到推荐停车点的骑行路径规划；
- **路径规划**：首页起终点规划（服务端拼写错误 `serachForPath`，客户端只能照抄）；
- **卡券档位**：本区域通勤卡档位（含赠品配置）、新版骑行卡商品列表；
- **反馈工单**：车辆问题反馈配置、工单提交（按类型决定字段可见性与图片数量）、工单列表/详情、处理结果评价。
