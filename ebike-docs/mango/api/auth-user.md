## 统计口径

`utils/util.js` 的 URL 表共 **100 个 key**，其中 2 个是外部占位（微信统一下单与接口凭证端点，均未调用），**98 个指向 `api.mangoebike.com`**，去重后对应 **76 条固定路径 + 16 条带路径参数（`{id}`）的模板 = 92 个业务路径模板**。叠加多方法复用（预约的 POST/GET/DELETE、券兑换与收藏的 GET/POST、订单的 POST/GET、工单的 POST/GET），**实际 (方法, 路径) 操作约 101 个**。

其中 **6 个 key 在已还原代码中从未被调用**（见[未定位调用点](./uncalled.md)）；另有 9 个 mall/address 明细 key 只在 `packages/shopping` 分包中使用，而**该分包源码未被还原**。

## 登录 / 用户 / 实名 / 信用能力类别

存在以下能力类别的接口（端点链与参数存档于私有仓）：

- **登录与会话**：code 换 openid（**服务端将 session_key 一并下发客户端**——弱点，见[认证与会话](../auth.md)）、三种方式共用的 token 端点（静默续登/手机号一键/短信验证码）、手机号密文解密、验证码下发（短信/语音）；
- **用户信息**：全量用户信息（实名态、信用、钱包、押金态、未付订单等）、账号注销；
- **实名认证**：明文提交姓名+身份证号（弱点：失败时经异常回捞端点二次上报，见[隐私与合规观察](../findings.md#隐私与合规观察)）；
- **协议授权**：授权开关读写（武大信息授权、骑行规则视频已看；licenseId 已脱敏）；
- **邀请与分享**：邀请统计、小程序码生成（其中一处调用为无效残留）；
- **信用分**：变动流水（游标分页）、按订单查询单笔变动；
- **钱包与押金**：钱包/押金/免押卡配置查询（含免押+通勤套餐）、自动退款申请与撤销、人工退款申请历史与提交（银行卡 Luhn 与手机号/邮箱前端校验）、武大游客押金状态（端点细节存档于私有仓）；
- **卡券**：我的卡券列表、兑换页配置与券码兑换；
- **收货地址**：列表（详情/编辑/设默认的调用点在缺失的 shopping 分包，见[未定位调用点](./uncalled.md)）。
