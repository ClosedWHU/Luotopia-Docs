对「知音出行」与「芒果电单车」两个共享电单车微信小程序的接口、认证与加密机制的静态分析整理，供珞家相关功能开发时参考。

> [!CAUTION]
> **脱敏说明** — 本分区为**公开脱敏版**：所有硬编码密钥、签名盐、AES key/IV、第三方 token 等敏感值均已移除，签名构造、指令协议与接口级复现细节亦已移入私有仓 `whu-ebike-re`，公开侧仅保留架构描述、弱点类别、研究方法与结论。内容来自对小程序客户端包的静态逆向，仅供安全研究与互操作性参考，请勿用于未授权测试。

## 两家对比

| 维度 | 知音出行 | 芒果电单车 |
|---|---|---|
| appid | `wx8df7475fde0271c6` | `wxbd322b1a1127faee` |
| 运营方 | 湖北知音动漫有限公司 | mangoebike.com（南宁交投运营） |
| 技术栈 | uni-app / Vue2（小安科技 SaaS 白标租户） | 原生小程序 |
| 业务网关 | `https://ebike-client-prod2.xiaoantech.com` | `https://api.mangoebike.com`（前缀 `/miniMango/v1/*`） |
| 接口风格 | 全部 POST + JSON，约 344 个 | RESTful（GET/POST/DELETE 混合），约 92 个路径 |
| 请求签名 | 客户端硬编码盐值的 SHA256 请求头签名（盐已脱敏；构造细节存档于私有仓 `whu-ebike-re`） | 客户端硬编码密钥的 HMAC-SHA256 请求头签名（密钥已脱敏；构造细节存档于私有仓 `whu-ebike-re`） |
| 认证 | OAuth2：token 端点 → Bearer accessToken，静默刷新 | JWT Bearer |
| 报文加密 | 实名字段 AES-256-CBC（口令已脱敏） | 设备信息 AES-256-CBC 上行、`joker` 标志响应 AES 下行（key/IV 已脱敏） |
| 车辆状态通道 | 后端接口 + BLE 双通道（开锁可走蓝牙） | 10s 轮询，无长连接、无 BLE |
| 支付 | 微信支付（宝付通道）+ 支付分 + 云闪付免密 + 代付 | 微信支付 + 押金/免押 |

## 来源与方法

- 样本：微信 PC 4.x 与 Android 客户端的小程序包缓存（`.wxapkg`），经解密/解包还原为可读源码后静态分析。
- 分析日期：2026-09-06；知音客户端版本 5.23.0（v50），芒果 v235。
- 两家接口清单均来自客户端源码中的 API 定义模块与调用点，未发起任何真实请求验证；响应结构以代码中的字段访问为准。接口级参数表与复现要素仅存档于私有仓 `whu-ebike-re`。
