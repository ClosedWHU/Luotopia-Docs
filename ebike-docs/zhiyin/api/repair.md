## 报修 / 违章上报能力类别

本组约 7 个接口，存在以下能力类别：

- **报修项配置**：按车辆、按车型两套配置查询；
- **报修提交**：新版与旧版两个提交端点（含照片上传）；
- **报修查询**：报修记录列表、报修详情/进度；
- **违章上报**：违章/暗哨上报。

调用方：`pagesSub/repair/*`（提交/记录/进度）、`pagesSub/violationReport`、`pagesSub/objection`（费用异议关联）；骑行页按还车前置校验返回的开关显示报修入口。完整接口清单存档于私有仓 `whu-ebike-re`。
