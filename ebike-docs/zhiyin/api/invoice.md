## 发票能力类别

本组约 7 个接口，存在以下能力类别：

- **开票**：申请开票、开票记录分页、开票设置（抬头）；
- **可开票数据**：可开票金额、已开票订单列表；
- **卡券账单**：押金卡开票账单、骑行卡开票列表。

调用方：`pagesSub/selectInvoiceType|issueInvoice|invoiceHistory|invoiceDetail|ridingCardInvoice|vipCardInvoice`。完整接口清单存档于私有仓 `whu-ebike-re`。
