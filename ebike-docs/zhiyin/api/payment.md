## 支付 / 充值 / 钱包 / 微信支付分能力类别

本组约 48 个接口（支付/充值/钱包 38 ＋ 微信支付分 10）。支付为**服务端签名的微信 JSAPI**，客户端零加工透传（见[支付流程](../flows/payment.md)）。

- **支付核心**：创建支付单（返回 wx.requestPayment 参数）、代付订单创建、支付取消/异常上报、支付结果查询（云闪付/免密轮询）、支付渠道读改、支付成功上报；
- **充值/钱包**：充值档位与营销配置、充值范围、用车前充值拦截配置、钱包信息（余额/押金）、购买/消费/退款记录；
- **押金与退款**：押金缴纳记录、押金退款、余额退款申请/状态/明细、退款引导弹窗开关；
- **订单侧**：最近订单、订单冻结/查询冻结/冻结转支付、引导充值、关闭订单、骑行卡购买标记、还车费钱包抵扣、免除调度费；
- **校园一卡通**：绑定/解绑/查询/支付密码校验四端点（密码在服务端校验，端点细节存档于私有仓）；
- **微信支付分**：授权记录查询、创建支付分订单（免押骑行）、押金确认渠道查询与确认订单创建（返回 openBusinessView 参数）、订单完结（扣款）、按骑行订单查支付分单、确认记录刷新、确认过期时间更新、解约、骑行权限配置。

调用方：payMoney mixin、`pagesSub/charge|chargeList|wallet|refundableBalance|retunDeposit|depositCardStore|obtainQualification`、支付页族 `pagesSub2/pay/*`。完整接口清单与通道枚举存档于私有仓 `whu-ebike-re`。
