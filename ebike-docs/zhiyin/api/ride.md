## 车辆 / 骑行控制（网络通道）能力类别

本组约 36 个接口。车辆状态查询、网络开锁/还车、临时停车、头盔锁、拍照还车审核等指令类接口存在；**开锁类接口（权限校验与网络开锁）受同盾 deviceToken 防护**（见[请求与签名](../signing.md)），流程见[车辆控制流程](../flows/unlock-return.md)。

- **用车前**：扫码数据上报、按车辆 ID 取用车页数据、开锁权限校验与预构建（deviceToken 防护）；
- **开锁/还车指令**：网络开锁（电单车/普通单车分支）、网络还车（分支同前）、开锁失败上报；
- **骑行中**：骑行订单/车辆状态轮询、骑行车辆信息、临时锁车/临时解锁/结束临停、临停次数限制与解锁配置、安全骑行放弃弹窗上报、订单解冻；
- **还车审核**：拍照还车资格/审核创建、是否在停车点判定、AI（VLM）还车照片识别、部件匹配（含临停场景）、四色车拍照校验、还车配置；
- **头盔锁**：开/关头盔锁、头盔照片绑定订单；
- **调度与寻车**：运营寻车通道、即将使用骑行卡查询、开锁失败召回活动。

调用方：`common/vendor.js` 用车 mixin 与 `pagesSub2/riding`。完整接口清单存档于私有仓 `whu-ebike-re`。
