## 广告能力类别

本组约 26 个接口，存在以下能力类别：

- **广告配置**：广告位配置查询、广告配置 V3、游客配置、智能广告屏蔽配置、广告指令透传内容；
- **上报**：曝光/点击/关闭三类上报、半屏小程序广告展示频控；
- **激励与奖励**：激励视频广告展示判断与奖励发放、看广告得钱包奖励判断、秒杀资格检查、积分同步、广告优惠券用户标记；
- **福利中心**：配置列表、进入判断与进入上报；
- **广告反馈/投诉**：类型列表、提交反馈、反馈分页、回复详情与回复提交、可投诉标记；
- **链接监测**：第三方（泽盛）广告链接监测；
- **第三方端点**：adwke「广宣」广告配置拉取（独立第三方主机，无业务签名，见[第三方主机](../overview.md)）。

调用方：广告组件族（`components/x-ad` 等）、`pagesSub2/welfareCenter|adFeedback|adFeedbackList|adFeedbackDetail`、支付完成广告页（见[支付流程](../flows/payment.md)）；juju 广告端点走独立签名（见[请求与签名](../signing.md)）。完整接口清单存档于私有仓 `whu-ebike-re`。
