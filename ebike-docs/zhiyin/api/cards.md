## 卡券 / 营销 / 活动 / 邀请 / 抽奖能力类别

本组约 57 个接口，存在以下能力类别：

- **卡券持有与购买**：骑行卡/优惠卡/折扣卡/免单卡/押金卡的我的列表与在售列表、卡详情与规则、续费引导、弹窗频控、支付页推荐骑行卡配置、累计节省金额、订单标记购卡；
- **优惠券/代金券**：租户与用户优惠券列表、订单可抵扣标记、角标、抵扣使用、代金券领取与码校验；
- **活动中心**：活动列表（含常驻）、活动详情、参加、领奖、注册/实名奖励、秒杀购买、短信召回奖励、年度奖励（两版）与年度骑行报告；
- **邀请与助力**：创建邀请/接受邀请/邀请详情/记录/规则、助力活动创建/详情/助力；
- **抽奖**：机会查询、活动详情/列表、抽奖、中奖记录（含分页与收货地址填写）——抽奖页面 `pagesSub4/lotteryActivity|luckyLot` 源码缺失，页面调用方无法证实；
- **押金配置**：押金档位配置列表；
- **账户**：账户资产汇总（卡券页）。

调用方：`pagesSub/myCard|cardCenter|activityCenter|activityDetail|invitePolite|voucher|depositCardStore|wallet|rules`、`pagesSub2/inviteHelp|pay`。完整接口清单存档于私有仓 `whu-ebike-re`。
