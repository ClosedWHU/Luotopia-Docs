## 系统配置 / 文件 / 地理能力类别

本组约 9 个接口，存在以下能力类别：

- **租户配置**：运行时配置（App onShow 拉取）、登录/实名相关配置、动态功能配置；
- **协议文档**：按类型获取默认协议文档；
- **文件上传**：通用文件/图片上传（`uni.uploadFile` 通道，签名方式见[请求与签名](../signing.md)）；
- **地理服务**：逆地理编码（高德后端代理，单点与批量两接口）、两点距离几何计算；
- **频控**：菜单点击频率限制/是否展示。

调用方：`common/main.js`（租户配置）、请求封装层（上传）、登录配置与逆地理封装模块。完整接口清单存档于私有仓 `whu-ebike-re`。
