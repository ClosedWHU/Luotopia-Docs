## 订单 / 计费能力类别

本组约 11 个接口，存在以下能力类别：

- **订单查询**：订单列表（含代扣单/预约单双 tab 分页）、订单详情、最近一笔订单（无 orderId 时按用户查最近单）、骑行轨迹回放；
- **计费**：计费规则配置（单/多规则）、行程费用预计算、骑行卡免费时长抵扣计算；
- **预约订单**：预约订单分页、预约订单退款；
- **工单/申诉**：创建工单（费用异议/调度费）、工单申请校验。

调用方：`pagesSub/order|costDetail|tripMap|objection|accountRules`、支付页族 `pagesSub2/pay/*`（含支付结果轮询页：2s 轮询、上限 15 次后提示勿重复支付）。行程中轮询见[车辆控制流程](../flows/unlock-return.md)。完整接口清单存档于私有仓 `whu-ebike-re`。
