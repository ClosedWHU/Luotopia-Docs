## 统计口径与通用说明

- 除标注外均为 `POST` + JSON，走[请求封装层](../signing.md)（自动附加公共参数、签名头、认证头；开锁链路接口另加设备指纹头）。
- 独立端点（不在业务网关下）：域名池配置拉取（带完整签名）、日志批量上报 `/log/app` 与 `/log/event`（无签名，见[其他发现](../findings.md)）。
- `pagesSub3`/`pagesSub4`（抽奖、年度报告、互动弹窗、校园一卡通绑定、评价提交、信用分、骑行任务等页）无源码，相关调用方无法标注。

## 登录 / 用户 / 实名能力类别

本组约 83 个接口，存在以下能力类别：

- **登录与 OAuth2 会话**：token 端点（一键登录/免验证码/短信验证码/刷新共用）、社交账号列表与解绑、短时 token（H5/webview 免登）、openid/buyer_id 换取；流程见[认证与会话](../auth.md)。服务端登出接口无调用方（弱点，见[认证与会话](../auth.md)）。
- **实名与人脸核验**：实名提交/状态/按手机号与 pin 查询、单次实名支持查询、人脸核验 ID（微信/腾讯 H5 两渠道）、用车前人脸检查与结果上报、人脸认证配置。
- **换绑与注销**：换绑申请/原号校验/人脸方式/免审核/取消，注销前置查询与提交。
- **信用分**：围栏与用户信用分配置、禁骑详情、流水分页、学习恢复与学习入口开关、学习免除调度费/罚款及其按钮开关。
- **用户信息与配置**：用户信息、协议同意上报、隐私政策状态、用户功能开关、特殊配置、租户配置与功能开关、实验分组与分桶骑行卡、定位上报（换取所在服务区）、用车资格（押金/免押）列表、黑名单详情。
- **职业认证**：学生/教师等材料上传与取消。
- **微信支付分授权**：授权记录查询/申请/解除。
- **营销与第三方**：注册奖励领取、未使用奖励资产、奖励卡、营销活动开关、实名奖励活动查询、公交换乘优惠、免密营销内容、支付宝免密代扣签约状态、第三方订单授权。
- **账户与碳积分**：用户账户信息、碳积分与兑换比率。
- **文件上传**：ebike-management 通道上传（走普通 JSON 请求层）。

调用方集中在 `common/main.js`、`pages/launch`、`pagesSub2/quickLogin|phoneLogin|smsVerification`、`pagesSub2/verified`、`pagesSub/identityAuth|bindCard|proCertification|cancelAccount|wxPayScore|invitePolite` 等页面。
