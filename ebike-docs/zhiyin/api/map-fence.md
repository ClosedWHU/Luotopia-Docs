## 地图 / 围栏 / 寻车 / 预约能力类别

本组约 30 个接口，存在以下能力类别：

- **服务区与电子围栏**：按定位取服务区、按服务区取围栏与详情、附近电子围栏查询（该接口在请求层被标记为禁止重试）；
- **附近车辆与停车点**：附近车辆位置（地图打点轮询）、附近停车点数量；
- **首页运营位**：活动入口（按服务区/按 ID）、滚动公告、首页导航配置、资源位小程序跳转列表与曝光/点击上报、骑行任务展示与完成提示；
- **寻车与语音**：寻车喇叭/语音、开锁后播放语音；
- **导航**：导航到车辆或停车点（后端高德代理）、导航开始/结束上报；
- **预约用车**：发起预约、取消（两版）、预约单详情、最近预约单；
- **配置与其他**：计费规则配置（token 失效豁免名单内）、数据字典、氢能源车通用开关、云闪付营销活动配置、微信支付分订单取消。

调用方：`pages/map/map.js`（服务区/附近车辆/计费配置轮询）与用车 mixin（预约/寻车/导航）。

> [!NOTE]
> 预约计费查询函数引用了不存在的 URL 常量，为死代码，未计入接口总数。完整接口清单存档于私有仓 `whu-ebike-re`。
