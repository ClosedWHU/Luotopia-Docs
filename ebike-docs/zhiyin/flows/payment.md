核心为 `common/vendor.js` 中的 payMoney mixin（被卡券/押金组件及分包支付页混入）。支付为**服务端签名的微信 JSAPI**（知音生效通道 = BAOFU_WXLITE 宝付）；存在押金/免押/校园一卡通等路径。

## 微信支付（JSAPI）

1. **前置**：校验售卖类型（充值/押金/押金卡/骑行卡等）与金额（分为单位）；30 秒防重复支付（本地记录支付动作）；实名检查（未实名弹窗引导）。
2. **openid**：登录态缺失时经 `wx.login` code 由服务端换取 openid（弱点类别：openid 为客户端可控输入，服务端未强制从会话反查）。
3. **创建支付单**：服务端下单接口按通道类型创建支付单；通道枚举共 21 种（微信系/支付宝系/云闪付免密/富邦插件/校园一卡通等，报文结构与通道清单存档于私有仓 `whu-ebike-re`）。
4. **拉起收银台**：后端返回 `wx.requestPayment` 所需的时间戳/随机串/package/签名类型/paySign 等参数，客户端**原样透传、零加工**——支付签名全部由服务端（宝付/微信商户）计算，客户端不参与（正面观察）。
5. **特殊通道**：
   - 云闪付免密：跳转云闪付小程序（回跳按 appid 识别），或短窗口轮询服务端查单接口；
   - 富邦插件支付：经 `fuiou-pay` 插件拉起，失败自动降级普通微信支付；
   - 校园一卡通：密码弹窗输入支付密码后由服务端校验（校验端点存档于私有仓）。
6. **失败/取消**：取消上报；非微信通道失败自动兜底重试微信支付；重复支付错误码触发确认弹窗（可强制重下）。
7. **成功后**：支付成功上报；按广告配置可能先经支付结果广告页（展示金额与支付时间、挂载广告位）再继续正常流程；另有独立支付结果轮询页（2s×15 次查单，见[订单/计费接口](../api/order.md)）。

## 代付 / 免押 / 钱包

- **代付（帮我付）**：分享前由服务端创建代付订单，分享卡片携带订单号与代付人标识；代付落地页已登录直接取参、未登录先存本地再跳登录回调续接；支付请求附代付信息（支持跨服务区代付）；调度费短链代付为独立分支。
- **隐藏「知音指令」组件**：pay 页存在一个固定定位在可视区外的隐藏 `code-btn` 插件组件，触发后会获取短信验证码并**将验证码与订单数据一并转交插件**（弱点：短信验证码离开小程序信任边界；字段清单存档于私有仓 `whu-ebike-re`）。该组件未在 `app-config.json` usingComponents 中注册，疑为小安多端复用的支付宝「吱口令」代付能力遗留，微信端实际不可达（见[其他发现](../findings.md)）。
- **钱包抵扣**：还车费/预约费钱包抵扣；欠款弹窗引导充值页（含校园一卡通密码支付分支与用车前充值拦截配置）。
- **退款**：余额退款申请/状态/明细，押金退款（页面 `pagesSub/refundableBalance`、`pagesSub/retunDeposit`）。
- **冻结单**：订单冻结/查询冻结/冻结转支付，支付分订单页有「支付停留超时」弹窗。

## 行程计费

- 计费规则配置（地图页与支付页展示费率，支持多规则）；
- 行程中订单/车辆状态轮询（节奏见[车辆控制流程](./unlock-return.md)）；
- 预估/结算：还车前费用预估、骑行卡免费时长抵扣、订单详情与轨迹回放；
- 调度费/罚款：调度费免除、学习免罚、还车前置校验返回的罚金字段。

计费相关端点清单存档于私有仓 `whu-ebike-re`，能力类别见[订单/计费接口](../api/order.md)。
