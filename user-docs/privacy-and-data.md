# 隐私与数据

界面文案与法律文档以 App 内 **关于 / 法律** 页面为准。本文是操作向摘要。

## 存在本机的数据

| 类型 | 说明 |
|------|------|
| 课表、成绩、日程 | 默认本机；换机需导出/重导 |
| 武大教务会话 | 本机 Cookie / 会话，**不**上传珞家业务服 |
| AI 密钥与会话 | 本机；请求直达用户配置的第三方 |
| 热更新脚本缓存 | 本机；源文件来自官网，经签名校验 |

## 会发往珞家业务服的

| 类型 | 说明 |
|------|------|
| 珞家登录 / 资料 / 会话 | 账号体系 |
| 论坛、课程评价等 | 需珞家登录 |
| 评价资格同步 | 课程标识等最小数据，**无**教务 Cookie |
| 设备推送 token（若启用） | identity 设备注册 |

## 会发往官网 / 第三方的

| 类型 | 说明 |
|------|------|
| 检查更新 | 官网 `releases` 接口 |
| 热更新 manifest / 脚本 | 官网静态资源 |
| 天气 | 用户所选第三方天气 API |
| 法律页 / 友情链接 | 官网静态 |

自定义业务服务器（开发者选项）**不会**改官网地址。

## 遥测

分析、崩溃、性能等 **默认关闭**，可在设置隐私相关项中按需开启（以当前版本为准）。
