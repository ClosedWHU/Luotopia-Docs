# 成绩与学业

## 成绩

入口：**校园 → 成绩**（页面标题为「成绩查询」）。

### 导入

先登录 [武大账户](./accounts#武大账户)，再进入 **成绩导入**。可选方式：

| 方式 | 说明 |
|------|------|
| 本科教务 | 成绩较完整；更新可能较慢；可能需要验证码 |
| 可信电子凭证 | 下载官方中文成绩单并在本机解析 |
| 专业发展指导系统 | 多为绩点信息，更新往往更早，明细通常不如教务完整 |

成绩保存在本机，用于查看与 GPA 计算。

### 浏览与 GPA

成绩按学期分组。可查看分数段分布、挂科标记，以及总 GPA、总学分。

在成绩相关设置中可切换 **GPA 计算标准**（如武大 2021+、WES、标准 4.0、百分制均分），切换后会重新计算汇总。

### 隐私锁

开启 **生物识别锁** 后，成绩单先显示「已被隐私锁保护」，点击后通过 Face ID 或指纹解锁。适用于不希望成绩立即可见的情况。

### 同步（课程评价资格）

在 **教务枢纽** 提交课程评价前，通常需要将本机成绩中的课程标识同步到珞家服务器（不上传教务 Cookie）：

1. 登录 [珞家账户](./accounts#珞家账户)。  
2. 在成绩或课评相关页面执行同步。  
3. 同步结果用于修读资格判定。  

导入或解析失败时，可检查武大登录，并在 **设置 → 热更新** 更新相关解析脚本。

## 学业状态

可从成绩页中的学业状态入口，或校园中的其他入口进入。需要武大账户登录，用于查看培养方案与修读进度。上游系统异常时可稍后重试。
