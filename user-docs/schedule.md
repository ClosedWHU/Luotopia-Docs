# 日程与事项

底部 **日程** 用于管理本机事项（任务、活动等）。

## 列表

打开日程后，可通过顶栏在「待处理」「进行中」「已结束，等待完成」「已完成」等状态间切换。点击事项进入详情，可编辑或删除；对已结束事项可多选后标记完成或删除。通过添加按钮新建事项。

列表页可单独设置壁纸（**设置 → 壁纸** 中与任务列表对应的目标）。

## 新建与编辑

可通过以下方式进入编辑：

- 在日程中新建  
- 在主页空白区域长按（时间按格子预填）  
- 在空闲教室、运动场馆等页面选择「加入日程」  

编辑页常见字段：类型、标题、详情、地点、起止时间、颜色、提醒、重复、完成方式；课程类型还可填写性质、教师等。若与已有事项时间重叠，会提示冲突，仍可保存。

## 提醒

编辑事项 → 提醒，选择提前通知时间。需要系统通知权限；Android 上若需准时提醒，还需精确闹钟权限。可在首次引导、**设置 → 通用设置** 或系统设置中开启。提醒未出现时见 [常见问题](./faq)。通知渠道与权限也可在 **设置 → 通知** 中查看。

复杂重复规则与部分系统通知能力仍在完善；基础提醒以当前版本可用功能为准。

## 重复

编辑事项 → 重复，可选择不重复或按日、周等规则。更复杂的规则未必全部支持。

## 与主页的关系

主页时间网格会展示课程与未完成的日程事项；在主页点击事项同样可以进入详情与编辑。时间块划分、是否隐藏午休等在 **设置 → 主页 / 时间网格** 中调整。
