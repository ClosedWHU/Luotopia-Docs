珞家使用两套独立账号，用途与登录入口不同。

| | 武大账户 | 珞家账户 |
|--|----------|------------------|
| 用途 | 导入课表与成绩、学业状态、自习预约、运动场馆、E 卡、邮箱、消息、校医院等校内服务 | 论坛、课程评价、登录会话与账号安全 |
| 入口 | **设置** 顶部「武大账户」；使用相关功能时也会要求登录 | **设置** 顶部「珞家账户」（未登录时显示「未登录」） |
| 是否发往珞家服务器 | 教务 Cookie / 密码 **不** 上传业务服 | 是（登录与云端 API） |

## 武大账户

1. 打开 **设置 → 武大账户**。  
2. 按页面完成登录或绑定。  
3. 登录后可查看学院、专业、班级等信息，并可重新绑定或退出。

教务会话与凭证保存在本机，用于访问武大相关系统；武大密码不会提交给珞家服务器代管。E 卡、智慧珞珈等页面通过本机会话打开校内网页。

未登录武大账户时，课表导入、成绩、自习预约等功能不可用。

## 珞家账户

1. 打开 **设置 → 珞家账户**。
2. 登录：用户名或邮箱，以及密码。
3. 注册：用户名至少 3 个字符，密码至少 6 个字符；邮箱可选。可用邮箱域名由服务器配置决定，常见要求包含 `@whu.edu.cn`。
4. 若启用了验证码、二次验证或 Passkey，按页面提示完成。

登录后可管理资料、登录会话（包括将其他设备下线）、安全选项、API 凭证，以及退出登录。

### 与武大账户的关系

仅登录武大账户即可使用大部分校园功能。提交课程评价需要：已登录珞家账户，并使用一次性 CAS service ticket 由服务器核验对应课程的修读资格；本机教务 Cookie 不会上传。详见 [成绩与学业](./scores.md)、[给分和评价](./campus.md#校历--全校课表--给分和评价)。
