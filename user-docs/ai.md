# AI

底部 **AI** 提供对话功能。模型与密钥由用户自行配置，与是否登录珞家账户无关。

## 配置

打开 **设置 → AI 设置**，填写：

| 项 | 说明 |
|----|------|
| AI 提供商 | 内置常用服务商，或选择自定义 |
| API 格式 | 自定义时按服务商接口类型选择 |
| API 地址 | 服务商 Base URL |
| API 密钥 | 仅保存在本机，请妥善保管 |
| 模型 | 手动输入，或获取模型列表后选择 |
| 系统提示词 | 在“模型参数”区域展开后编辑，可选 |

填写后可使用 **连接测试** 验证，再 **保存 AI 设置**。

## 使用

打开 **AI**，在输入框发送消息。顶部显示当前会话标题，支持新建、切换、重命名、置顶与删除会话。会话保存在本机，下次启动可恢复。

默认输入区只显示模型选择、附件、语音输入和发送操作。需要调整自动化级别、助手、技能或 MCP 时，展开输入区上方的高级控制；这些设置会影响后续请求。

支持图片、文件、语音识别和朗读，具体入口会根据当前模型能力显示。执行校园数据操作时，AI 可能要求登录、人工验证或确认，用户确认后才会继续；完成后可从结果卡片跳转到对应功能页面。

## 故障排查

优先检查 API 地址、密钥、模型名称与网络连通性，而不是珞家登录状态。若设备无法访问所配置的 API，需自行调整网络环境。用量与计费以服务商账单为准。

AI 标签可在 **设置 → 通用 → 导航栏** 中显示或隐藏；与是否登录珞家无关。
